主な機能

📊

テーブルブラウザ

スキーマ確認、データ閲覧・編集。直感的なUIで複数のD1データベースをタブで管理できます。

⚡

SQLエディタ

シンタックスハイライト付きでクエリを作成・実行。Cmd+Enterで即座に実行できます。

📁

インポート/エクスポート

CSV、JSON、SQL、MySQLダンプ形式に対応。データの移行やバックアップが簡単です。

🔄

スキーマ比較

2つのデータベース間のスキーマ差分を比較し、マイグレーションSQLを自動生成します。

💡

スマートSQL提案

テーブル構造に基づいたクエリ提案。すべてローカルで処理され、データは外部に送信されません。

🔗

ローカルDB対応

wranglerのローカルD1データベースに直接接続。開発中のテストに便利です。

安全機能

本番データを守るための機能を標準搭載

🏷️

環境バッジ

DEV / STG / PROD を視覚的に識別。今どの環境にいるか一目でわかります。

🔒

本番ロック

本番環境での危険な操作をブロック。意図しないDELETEやDROPを防ぎます。

⚠️

危険クエリ検出

WHERE句なしDELETEやDROP TABLEを実行前に警告。確認ダイアログで安全を確保。

📝

監査ジャーナル

すべてのデータ変更を記録。ロールバックSQLを自動生成し、誤操作からの復旧を支援。

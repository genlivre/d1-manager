D1 Manager Privacy Policy

Last updated: December 15, 2024

Overview

D1 Manager ("the App") is a desktop application for managing Cloudflare D1 databases. We are committed to protecting your privacy.

Data Collection

We do not collect any personal data.

The App does not:

  • Collect or transmit personal information
  • Use analytics or tracking services
  • Store data on external servers
  • Share any information with third parties

Local Data Storage

The App stores the following data locally on your device:

  • Connection profiles: Database connection settings (stored in local files)
  • API tokens: Cloudflare API tokens (stored securely in macOS Keychain)
  • Query history: SQL queries you execute (stored locally)

This data never leaves your device except when communicating directly with Cloudflare's API using your credentials.

Network Communication

The App communicates only with:

  • Cloudflare API (api.cloudflare.com): To execute database queries using your API token

All communications are encrypted using HTTPS.

Third-Party Services

The App does not integrate with any third-party analytics, advertising, or tracking services.

Children's Privacy

The App is a developer tool and is not directed at children under 13.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be posted on this page.

プライバシーポリシー（日本語）

最終更新日: 2024年12月15日

概要

D1 Manager（以下「本アプリ」）は、Cloudflare D1データベースを管理するためのデスクトップアプリケーションです。お客様のプライバシー保護に努めています。

データ収集について

本アプリは個人データを一切収集しません。

本アプリは以下を行いません：

  • 個人情報の収集・送信
  • アナリティクスやトラッキングサービスの使用
  • 外部サーバーへのデータ保存
  • 第三者への情報共有

ローカルデータ保存

本アプリは以下のデータをお使いのデバイスにローカル保存します：

  • 接続プロファイル： データベース接続設定（ローカルファイルに保存）
  • APIトークン： Cloudflare APIトークン（macOSキーチェーンに安全に保存）
  • クエリ履歴： 実行したSQLクエリ（ローカルに保存）

これらのデータは、お客様の認証情報を使用してCloudflare APIと通信する場合を除き、デバイスから外部に送信されることはありません。

ネットワーク通信

本アプリは以下とのみ通信します：

  • Cloudflare API (api.cloudflare.com)： お客様のAPIトークンを使用してデータベースクエリを実行

すべての通信はHTTPSで暗号化されています。

サードパーティサービス

本アプリは、アナリティクス、広告、トラッキングなどのサードパーティサービスを一切使用していません。

お子様のプライバシー

本アプリは開発者向けツールであり、13歳未満のお子様を対象としていません。

ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。変更がある場合は本ページに掲載します。
